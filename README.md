# Jetson Allto — Personal Portfolio

A dark-themed personal portfolio website built from scratch with React, Vite, Tailwind CSS, Framer Motion, and Lucide Icons.

## Features
- Deep Black (`#080D1B`) & Dark Navy (`#111D3A`) theme with Royal Blue (`#244B9B`), Sky Blue (`#55A6FF`), and Lavender (`#B7A5F5`) accents
- Smooth typewriter animation for name (`JETSON ALLTO`) and rotating professional roles
- Scroll-triggered zip reveals respecting `prefers-reduced-motion`
- Dedicated sections for Hero, About, Technical Skills, Projects, Internship Experience, Education, Resume (`View` & `Download` official PDF), and Contact (`mailto:`, `tel:`, WhatsApp, LinkedIn, configurable GitHub)
- Vercel-ready static build (`vercel.json` included)

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```
